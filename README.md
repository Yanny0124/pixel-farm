# Tiny Pixel Farm

一个基于 HTML5 Canvas 的像素农场经营游戏。玩家从一片小农田开始，逐步解锁作物、动物、加工建筑、访客剧情、奇迹建设和结局收藏。

当前版本是纯前端静态项目，不需要后端，也不需要构建工具。

## 在线游玩

如果本项目已经部署到 GitHub Pages，可以直接打开仓库 Pages 地址游玩。

本地游玩也很简单：

1. 下载或克隆本仓库。
2. 双击 `index.html`。
3. 使用 Chrome、Edge 或 Firefox 打开。

## 游戏内容

- 作物种植：多阶段生长、等级解锁、隐藏作物、变异作物。
- 畜牧系统：鸡、羊、牛、蜜蜂、小猪，以及饲料和稀有产物。
- 加工系统：磨坊、番茄酱工厂、面包房、奶酪坊，支持加工时间和自动加工。
- 市场与订单：价格波动、手动输入售卖数量、外部订单看板。
- 访客剧情：雷欧、莉亚、布鲁诺、阿米尔的任务链和入驻。
- 手札图鉴：作物、动物、产物、信件、天赋、奇迹、访客、结局收藏。
- 奇迹建设：先祖灌溉渠、永恒谷仓。
- 辅助体验：缩放视野、离线结算、天气昼夜、基础触摸操作。

## 操作方式

- 左键：种植、收获、放置动物、点击 UI。
- 右键：查看地块信息。
- 鼠标滚轮：缩放视野，窗口内容区域内用于滚动。
- Space / 鼠标中键：拖动画面。
- 触摸屏：点击操作，拖动视野，长按查看地块信息。

## 项目结构

```text
.
├── index.html          # 游戏入口
├── style.css           # 页面布局样式
├── js/
│   ├── config.js       # 作物、动物、建筑、剧情、奇迹等配置
│   ├── state.js        # 存档、全局状态、图鉴和解锁
│   ├── input.js        # 鼠标、滚轮、触摸输入
│   ├── main.js         # 初始化和主循环
│   ├── logic/          # 农场、动物、市场、天气、访客等逻辑
│   ├── render/         # Canvas 渲染、像素绘制和特效
│   └── ui/             # Canvas UI 和兼容入口
└── dist/pixel-farm/    # 生成的玩家版发布目录
```

## 存档说明

存档保存在玩家浏览器的 `localStorage` 中。不同浏览器、不同电脑、不同部署地址之间不会自动共享存档。

如果需要重新开始，可以在游戏设置中点击“重置世界”。

## 开发说明

项目目前保持静态文件结构。新增脚本时，需要在 `index.html` 中按依赖顺序加载。

发布给普通玩家时，推荐分享：

```text
dist/pixel-farm-playable.zip
```

这个压缩包只包含运行所需文件，不包含计划书、开发素材和 Office 临时文件。
